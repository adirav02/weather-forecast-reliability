# Weather Forecast Reliability Platform

A data project for analyzing how accurate historical temperature forecasts were compared with the weather that actually occurred.

## Project Goal

The goal is to measure forecast accuracy and understand how it changes according to factors such as:

* Forecast lead time
* Location
* Time of day
* Month and season
* Weather conditions

The first version of the project will focus on comparing historical forecasts with observed temperatures and calculating forecast errors.

In the future, the project may also estimate how reliable a new forecast is expected to be based on previous forecast performance.

## Current Stage

The project is currently in its initial SQL and PostgreSQL stage.

The current focus is on:

* Understanding the available weather data
* Loading sample data into PostgreSQL
* Connecting forecasts with matching observations
* Calculating and analyzing forecast errors
* Identifying missing, duplicated, or inconsistent data

## Planned Development

The project is expected to develop gradually into a larger data system that includes:

* Automated data collection with Python
* Data validation and quality checks
* PostgreSQL analytics
* A FastAPI backend
* A scheduled data pipeline
* A future forecast reliability model
